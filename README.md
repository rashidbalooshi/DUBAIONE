# DUBAIONE

DubaiOne is a Flutter mobile app for independent UAE PRO, visa, immigration, business setup and document-clearance assistance.

## Services
- UAE Visa Services
- Golden Visa
- Family Visa
- Immigration Services
- Sponsor File
- Company Formation
- Document Clearance
- Government Transactions

## Run locally
1. Install Flutter stable.
2. Run `flutter pub get`.
3. Run `flutter run`.

## Android release
After the Android platform folder and signing configuration are generated in a Flutter environment, use `flutter build appbundle --release` to produce the Play Store AAB.

## Important
DubaiOne is an independent assistance service and is not a UAE government authority. Government approvals, official fees and eligibility are controlled by the relevant authorities.
